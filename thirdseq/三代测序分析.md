# 使用的工具是/tmpdata/LyuLin/bot/Nanodecoder/Nanodecoder，可以-h查看用法。用途：把 Nanopore 长读段变成按细胞 barcode 汇总的分子计数，回答“哪个细胞里检测到了哪些基因或转录本，各有多少个分子”。
# 需要知道的是，在建库的时候每个细胞的每个分子就都获得了barcode和UMI了，就知道哪个分子是哪个细胞表达的了。minimap2 把 read 比到参考基因组，给出它落在哪些位置、跨过哪些剪接位点。`parseBam` 再把这些信息和 GTF 中的基因、外显子及转录本结构对照。假如一条 read 跨过某个转录本特有的剪接位点，就有证据支持它来自那个转录本。如果它只覆盖几个转录本共享的外显子，可能只能判到基因，具体是哪一个转录本仍有歧义。所以这样就知道来自某个细胞的某个基因/转录本到底是什么了，因为只有UMI只能判断这个细胞表达了多少个RNA并不能知道这个RNA是什么，比对到基因组上之后就可以知道了。一条成功处理的 read 就有了类似“来自细胞 A，归到基因 G，UMI 是 U1”的记录。
## 根据要求我需要提供一个具有TSL标签的注释文件，因为内置的parseBam 只保留 TSL=1 的转录本
```
awk 'BEGIN{FS=OFS="\t"} $3=="transcript"||$3=="exon"{sub(/[ ;]*$/,"",$9); $9=$9"; transcript_support_level \"1\";"} {print}'     Yang-v2.annotation.v4.3.6.full.cellranger01.gtf > Yang-v2.cellranger.thirdseq.tsl1.gtf
# # 核对：transcript+exon 行数应该等于带标签的行数
awk -F'\t' '$3=="transcript"||$3=="exon"' Yang-v2.cellranger.thirdseq.tsl1.gtf | wc -l
grep -c 'transcript_support_level "1"' Yang-v2.cellranger.thirdseq.tsl1.gtf
```
## 另外根据要求我需要提供一个barcode白名单，但是默认的白名单是2016年10X官方的，所以我选择使用cellranger之后的barcode作为白名单，但是这个工具只能识别tsv所以需要转换一下

```
zcat /tmpdata/YangWenyan/yang-v2/count_all_v436/TF260113LMBL/outs/filtered_feature_bc_matrix/barcodes.tsv.gz  | sed 's/-1$//' > ./TF260113LMBL.barcode.lst
# 检查前三行，应该都是16bp
head -3 TF260113LMBL.barcode.lst; awk '{print length($0)}' TF260113LMBL.barcode.lst | sort -u
```
## 最后使用是这样的
```
# 因为fastq文件中四行一个完整的序列存储，所以这里提取了前100条序列也就是前400行
/tmpdata/LyuLin/bot/Nanodecoder/Nanodecoder \
-i TF260113LMBL_400.fastq \
-t 5 \
-r /tmpdata/YangWenyan/yang-v2/reference/yang-v2.polish.fa \
-a /tmpdata/YangWenyan/yang-v2/reference/latest_v4.3.6/Yang-v2.cellranger.thirdseq.tsl1.gtf \
-w ./TF260113LMBL.barcode.lst
```
### - 细胞归属：read 上的 barcode 序列和 Cell Ranger 白名单匹配，回答“这条 read 来自哪个细胞 barcode？”
### - 基因归属：minimap2 把筛选后的 Nanopore read 序列比到 yang-v2.polish.fa 参考基因组上，回答“它能对到基因组的哪些位置？”随后 parseBam 用 GTF 查这些位置对应哪些基因和转录本。
### 公开版 parseBam 的 hit 是一条已比对的 BAM 记录。如果一条 read 有一个主比对和两个次要比对，日志里可以贡献 1 条 read、3 个 hits。
